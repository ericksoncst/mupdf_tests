# MuPDF Sample Project

This is a C++ program using the MuPDF library to load and render PDF documents into images.

## Prerequisites

- A Linux-based system (tested on Ubuntu)
- **CMake** version 3.24 or higher
- **g++** compiler
- MuPDF (version 1.25.0)

## Setup

### Clone the Repository

Clone this repository to your local machine:

```bash
git https://github.com/ericksoncst/mupdf_tests
cd mupdf_tests


mkdir build
cd build

cmake ..
make

## RUN

./MuPDFSample
